Работа остановлена по просьбе координатора. Разбора (`2026-10-11-разбор.md`) НЕТ, он не написан.

- `2026-10-11-core.tsv` — черновое ядро, 15 639 фраз. Колонки: фраза; частотность «широкая/точная» (Букварикс, регион «Весь мир»); источник; кластер.

- `raw/` — сырые выгрузки: `bukvarix.tsv` (по длинным seed, 3 660 строк), `bukvarix2.tsv` (38 коротких «головных», 12 130), `bukvarix3.tsv` (повтор 429-х и доп. головы, 2 060), `suggest_0..3.tsv` (подсказки), `suggest.tsv` (обрывок первого запуска, 229 строк).

## Какие источники ответили
- Букварикс, бесплатный API: РАБОТАЕТ. Адрес `http://api.bukvarix.com/v1/keywords/?q=...&api_key=free&num=N&format=tsv` (документация: bukvarix.com/api_keywords.html). Возвращает фразу, число слов, символов, широкую и точную частотность. Частотность по региону «Весь мир», не по СПб и не по России. Без регистрации фильтры по частотности и словам недоступны (402). До 1000 строк на запрос. Лимит частоты: 429 после серии запросов с паузой 1.5 с, лечится паузой 20 с и повтором. Длинные нишевые запросы дают 0–20 строк, поэтому нужны короткие «головы» (подстроки).
- Подсказки Яндекса (`suggest.yandex.ru/suggest-ya.cgi?v=4&part=...&lr=2`, регион СПб): РАБОТАЕТ без аккаунта, но отдаёт 3–10 подсказок на запрос и без частотности.
- Подсказки Гугла (`suggestqueries.google.com/complete/search?client=firefox&hl=ru&gl=ru`): РАБОТАЕТ без аккаунта, без частотности.
- Подсказки Bing (`api.bing.com/osjson.aspx`): РАБОТАЕТ, без частотности (DuckDuckGo отдаёт то же самое, отдельно не собирал).
- Отказали (404): подсказки Mail.ru (`go.mail.ru/sug`), `suggest.dzen.ru`. YouTube suggest вернул 400 на моей форме запроса, глубже не разбирал.
- Платное и запрещённое (Wordstat API, Планировщик, Мутаген, Serpstat) не трогал.

## Где остановился
- Подсказки: 4 шарда по ~23 seed, 20 модификаторов (цена, заказать, спб, под ключ…) × 3 поисковика. Шарды убиты на середине (последние обработанные: «транскрибатор созвонов», «ии для протоколов совещаний», «обработка анкет автоматизация», «автоматизация обработки заявок»). НЕ успели пройти seed про ритейл, ивенты, туризм, фарму, недвижимость, образование, бренд, производство, n8n, продажи. Подсказок по этим нишам в ядре нет или мало.
- Букварикс: второй проход (38 голов) и третий завершены. 429 на «чат бот», «разработка crm», «внедрение ии» повторены в третьем проходе успешно.

## Качество черновика (честно)
- Ядро ШУМНОЕ. Фильтр в `build_core.py` грубый: пропускает любую фразу со словом «бот», «ии», «приложение» и т.п. (например, «приложение мероприятия» 4768 — это не про наш заказ). Нужна ручная чистка и отсев инфо-/потребительских запросов («скачать», «бесплатно», игры, боты-музыкальные).
- Кластер у фразы один, по первому сработавшему правилу. «Коммерческий против информационного» в TSV НЕ размечен.
- Частотность Букварикса: «Весь мир», историческая база сканов, это не Вордстат по СПб. Для СПб и Москвы цифр нет. Строки из подсказок без чисел намеренно пустые.
- В подсказках почти нет региональных хвостов СПб (17 строк со «спб/санкт» на всё ядро).

## Первые шаги при возобновлении
1. Дозапустить подсказки только для ненайденных seed (ритейл, ивенты, туризм, фарма, недвижимость, образование, бренд, производство, n8n, продажи): `python3 -I fetch_suggest.py <шард> <число>` — сначала поправить скрипт, чтобы он брал список seed из аргумента и писал в отдельные файлы (иначе перезапишет `suggest_N.tsv`).
2. Ужесточить фильтр в `build_core.py` (минус-слова: скачать, бесплатно, игра, музык, ростов… по результату просмотра) и добавить колонку «интент» (коммерческий: заказать/цена/разработка/под ключ/услуги/компания; инфо: как/что такое/своими руками/курс/бесплатно).
3. Написать `2026-10-11-разбор.md`: кластеры, где спрос есть (крупно: транскрибация, автоматизация бизнеса, создание чат-ботов, мини-аппы Telegram — сотни/тысячи), где почти нет (проверка выкладки по фото — 60–270; профильные запросы под каждый кейс), коммерческие против информационных. Цифры брать только из TSV.
