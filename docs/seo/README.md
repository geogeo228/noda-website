# Семантика: что здесь лежит и чему верить

Черновое семантическое ядро, собранное 11 октября 2026 из бесплатных
источников. Это **черновик**, а не готовое ядро: ниже честно сказано, где
ему верить нельзя.

## Файлы

- `2026-10-11-семантическое-ядро.tsv` — 15 639 фраз. Колонки: фраза;
  частотность «широкая/точная»; источник; кластер.
- `2026-10-11-состояние-сбора.md` — подробная записка сборщика: какие адреса
  API отвечают, какие отказали, где именно работа остановлена и что делать
  первым шагом при возобновлении. Читать её перед любым продолжением.
- `scripts/` — сборщики и склейка, плюс `seeds.tsv` с исходными запросами.

Сырые выгрузки (3.9 МБ) в репозиторий не кладём: они восстанавливаются
повторным запуском сборщиков, а ядро из них уже склеено.

## Три оговорки, без которых цифры врут

**Частотность по региону «Весь мир», а не по России и не по Петербургу.**
Букварикс в бесплатном виде региона не даёт. Для вопроса «что люди вообще
ищут» годится; для решения «делать ли страницу под этот запрос в СПб» — нет.
Точные цифры по Петербургу даёт только веб-Вордстат, выгрузкой из личного
аккаунта Яндекса.

**Широкая частотность складывает все словоформы.** Поэтому верхушка списка
выглядит так: «ботом чат», «бота чат», «бот чат», «бот чаты» — у всех широкая
349 тысяч, потому что это один и тот же запрос. Смотреть надо на точную:
у «бот чат» она 21 423, у «ботом чат» — 10.

**Ядро шумное и интент не размечен.** Фильтр пропускает любую фразу со словом
«бот», «ии», «приложение» — включая запросы, не имеющие к заказу разработки
никакого отношения. Коммерческие запросы (ищут исполнителя) от информационных
(ищут, как сделать самому) не отделены.

## Что из этого уже видно

Спрос есть там, где у нас мало кейсов, и почти отсутствует там, где кейсы
сильные. Транскрибация — 41 тысяча, автоматизация бизнеса — 12 тысяч,
«чат бот создать» — 8 тысяч. Проверка выкладки товара по фото, с которой
начинается наш самый сильный кейс, — 200–270.

Региональных запросов по Петербургу в ядре почти нет: 17 строк на 15 639.
А при нулевом трафике зацепиться можно именно за них — по запросу
«транскрибация» мы не выйдем, по «разработка телеграм-бота спб» можем.
Это и есть первая дырка, которую надо закрыть при возобновлении.

## Чего в сборщиках не хватает

Скрипты писались по ходу, тремя проходами, и это видно: у двух из трёх список
исходных запросов зашит внутрь, а не читается из `seeds.tsv`. `fetch_suggest.py`
при повторном запуске перезапишет уже собранные выгрузки — починить до того,
как запускать его снова.
